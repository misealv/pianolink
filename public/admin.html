📅 Integración Google Calendar

Configura las credenciales de Google Calendar para programar demos automáticamente con links de Google Meet.

⚠️ IMPORTANTE: Configuración inicial requerida

Antes de llenar este formulario, debes crear credenciales OAuth2 en Google Cloud Console. Ir a Google Cloud Console →

💡 Dónde conseguirlo: Google Cloud Console → APIs y servicios → Credenciales → ID de cliente OAuth 2.0

💡 Dónde conseguirlo: Mismo lugar que Client ID (se muestra al crear las credenciales)

💡 IMPORTANTE: Debes agregar esta URI en Google Cloud Console → Credenciales → URIs de redirección autorizadas

💡 Cómo obtenerlo: Después de guardar Client ID, Secret y Redirect URI, visita /api/calendar/auth para autorizar y obtener el refresh token. Luego pégalo aquí y guarda de nuevo.

📖 Guía de Configuración

  1. Crear proyecto: Google Cloud Console → Nuevo proyecto
  2. Habilitar API: APIs y servicios → Habilitar → Google Calendar API
  3. Crear credenciales: Credenciales → Crear → ID de cliente OAuth 2.0
  4. Configurar pantalla: Pantalla de consentimiento OAuth → Tipo: Externo
  5. Agregar Redirect URI: En credenciales, agregar la URI mostrada arriba
  6. Copiar credenciales: Client ID y Client Secret
  7. Pegar aquí: Llenar los campos de arriba
  8. Guardar: Clic en "Guardar Credenciales"
  9. Autorizar: Visitar /api/calendar/auth
  10. Copiar token: Pegar el refresh_token aquí y guardar de nuevo

✅ Beneficio: Una vez configurado, las demos se crearán automáticamente con links de Google Meet
